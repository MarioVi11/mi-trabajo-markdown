Mi instituto y Linux
Aprender informática con Debian

Linux es un sistema operativo muy útil para aprender informática. Es gratuito y de código abierto, permite aprender administración de sistemas y podemos utilizar comandos como ls para ver los archivos del ordenador.

Comandos de Linux
pwd
ls
mkdir ejercicios

Pasos para utilizar Debian
Encender la máquina virtual.
Abrir la terminal.
Escribir comandos.
Crear carpetas y archivos.
Ventajas de Linux
Es gratuito.
Es de código abierto.
Se utiliza en servidores.
Permite aprender informática.
